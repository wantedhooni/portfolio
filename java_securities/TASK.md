# 작업 내용

## 2026-03-20
- `web-ui` 프로젝트 구조를 확인했다.
- 공용 헤더와 홈 화면의 UI/UX 개선 작업을 진행한다.
- 로그인/회원가입 화면의 사용성을 개선한다.
- 루트 실행 스크립트와 README를 보완한다.
- 차트, 계좌, 환전, 주문 화면을 사람이 쓰기 편한 흐름으로 추가 개선한다.
- `web-ui` 전반을 토스 스타일에 가까운 밝고 정돈된 UI/UX 톤으로 재정리한다.
- 과한 데모/랜딩 느낌을 줄이고 실제 서비스처럼 더 심플한 톤으로 재정리한다.
- `web-ui` 환전 화면의 송금형 문구를 환전형 UI/UX로 수정한다.
- `web-ui` 거래/주문 화면의 렌더링 오류와 에러 표시 방식을 정리한다.
- `web-ui` 공통 헤더, 홈, 시장, 계좌 화면을 고객 포털 기준으로 전면 재구성한다.
- `web-ui` 전반의 에러 문구와 상태 표기를 사람이 읽기 쉬운 표현으로 통일한다.
- `web-ui` 공통 헤더와 홈, 전역 카드/버튼 스타일을 더 단순한 토스형 톤으로 다시 정리한다.
- `web-ui` 전체 화면의 카드 밀도와 문구를 더 단순하게 정리하고 모바일 주문 화면 깨짐을 줄인다.
- `web-ui`를 데스크톱, 태블릿, 모바일 구간별 반응형 레이아웃으로 다시 정리한다.
- `web-ui` 전역 셀렉트박스 스타일과 폭을 정리해 화면별로 깨지지 않게 맞춘다.
- `web-ui` 주요 화면 스크린샷을 촬영하고 이직용 포트폴리오 문서를 `output/doc` 에 생성한다.
- `web-ui` 거래, 계좌, 주문 화면을 요약-목록-액션 흐름으로 다시 정리해 한눈에 들어오도록 개선한다.
- `web-ui` 홈, 시장, 환전, 인증 화면의 카드 톤과 여백도 같은 규칙으로 맞춰 전체 UI를 균일하게 정리한다.
- `web-ui` 전역 셀렉트박스와 환전 통화 셀렉트의 폭, 여백, 화살표 위치를 조정해 잘림 현상을 줄인다.
- `web-ui` 거래 화면에서 구매 주문 카드만 과하게 길어지는 문제를 줄이기 위해 주문 폼을 요약형 2열 구조로 재구성하고 최근 주문 패널을 아래 전체폭으로 재배치한다.
- `web-ui` 계좌 화면을 계좌 선택과 빠른 작업 중심의 2단 워크스페이스 구조로 전면 개편해 더 심플하게 보이면서 입금, 출금, 이체, 개설을 한 곳에서 처리할 수 있게 정리한다.
