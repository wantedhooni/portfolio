# 작업 에이전트 지침

## 작업 범위
- 이 저장소는 `core-banking` 프로젝트 전용 작업공간이다.
- 같은 상위 디렉터리의 다른 프로젝트를 참고하거나 수정하지 않는다.
- 변경 전 기존 파일의 맥락과 현재 수정 상태를 확인하고, 사용자 변경을 되돌리지 않는다.

## 구현 원칙
- 실무 코어뱅킹 시스템을 기준으로 도메인, 보안, 트랜잭션, 운영 문서를 작성한다.
- 백엔드는 계층 경계와 트랜잭션 책임을 명확히 하고, 프론트엔드는 실제 운영자/사용자 흐름을 기준으로 화면을 구성한다.
- 클래스, 서비스, 서비스 메서드에는 한글 doc 주석을 작성한다.

## 문서화 규칙
- 작업 시작 시 `PLANS.md`에 계획을 남긴다.
- 각 작업은 `TASK.md`에 한글로 작업 내역을 기록한다.
- 작업 완료 후 루트 `README.md`를 업데이트한다.

## 실행 스크립트
- 프로젝트 단위 `script/` 디렉터리에 `all-start.sh`, `all-stop.sh`, `all-restart.sh`를 둔다.
- 시작/재시작 스크립트는 마지막에 접속 URL과 데모 계정 정보를 출력한다.
